# Katalon Petstore Web Automation

Project automasi pengujian antarmuka web (*Web UI Testing*) untuk aplikasi JPetStore menggunakan **Katalon Studio**.

## 🔗 Target Application
* **Website URL**: [https://petstore.octoperf.com/actions/Catalog.action](https://petstore.octoperf.com/actions/Catalog.action)

---

## 📋 1. Penjelasan Project
Project ini dirancang untuk menguji fungsionalitas sisi interface (Frontend/UI) pada platform JPetStore secara otomatis, memastikan elemen halaman, navigasi katalog, keranjang belanja, dan interaksi pengguna berjalan dengan baik.

## 🎯 2. Test Coverage & Test Suite
* **UI Navigation & Catalog**: Menguji navigasi halaman utama, kategori hewan, dan penelusuran produk.
* **User Interaction**: Memastikan fungsionalitas klik tombol, alur keranjang (*cart*), hingga proses *checkout*.
* **Positive & Negative Scenarios**: Validasi respons halaman terhadap interaksi benar maupun input data yang tidak valid.

## ⚙️ 3. Cara Menjalankan (How to Run)
1. Clone repository ini ke komputer lokalmu.
2. Buka **Katalon Studio** dan pilih menu **File > Open Project**, lalu arahkan ke folder project ini.
3. Buka **Test Suite** yang diinginkan melalui panel *Test Explorer*.
4. Klik tombol **Run** dan pilih browser (Chrome/Firefox) yang ingin digunakan untuk eksekusi.

**note:** ada bagian di saat menjalankan testcase positive yang saat dijalan nanti ada direct ke halaman eror saat di pengisian state itu nanti langsung direct ke eror page dan back saja biar tetap lanjut dan passed

## 🔒 4. Keamanan
Project ini dibuat untuk keperluan pembelajaran dan portofolio pengujian perangkat lunak. Bebas dari data sensitif atau kredensial rahasia.
